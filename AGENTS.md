# Agents

This is the Hope's Voice repository. It is maintained largely by automated agents, with tests and CI as the merge gate. Humans are welcome via issues and pull requests.

If you are an agent picking up work here, start with the maintenance loop skill:

- [`.agents/skills/maintenance-loop/SKILL.md`](.agents/skills/maintenance-loop/SKILL.md)

Read [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md) and [`STATUS.md`](STATUS.md) before you change product behavior. Merge to `main` only when tests are green. Never commit secrets or private family data. Use Grok models only.
